# 04. Игра без мяча

## 1. Целевая точка игрока

Сумма компонентов:
- якорь из схемы, смещённый по фазе (атака, оборона, переходы), положению мяча, стилю;
- смещение роли и привычек;
- назначенная роль в обороне (раздел 2);
- рывок (раздел 4);
- поправки линии обороны и компактности (раздел 3).

Движение к цели через steering с ограничениями физики. Интенсивность бега по срочности и `work_rate`.

## 2. Распределение ролей в обороне (`defense/`)

Раз в 0,5 с и по событию решается задача назначения: 10 полевых игроков обороняющейся команды на набор обязанностей. Венгерский алгоритм на матрице стоимости 10×N (N — число обязанностей), стоимость из модели прибытия, близости к якорю и роли.

Обязанности:
- **прессингующий** на владельца мяча (0 или 1, по триггерам и `press_intensity`);
- **поддержка прессинга**: перекрытие ближайших линий паса тенью прикрытия (0–2);
- **опека** конкретного соперника в опасной зоне (по схеме опеки стиля: при зональной только в штрафной и рядом с ней);
- **страхующий** за прессингующим;
- **зональные** позиции для остальных, чтобы держать форму.

Передача опеки: когда атакующий выходит из зоны игрока, он передаётся следующему по назначению, если `communication` линии (`teamwork`, `cohesion`) позволяет; иначе возникает разрыв, которым может воспользоваться атака.

Ограничения: из своей линии на прессинг выходит не больше заданного числа игроков; центральные защитники выходят из линии только по условию стиля.

## 3. Линия обороны и компактность

- Защитники согласуют x-координату линии; разброс по `concentration` и `cohesion` пар.
- Ловушка офсайда шагом вперёд по сигналу при `offside_trap`.
- Ограничение расстояния между линиями и ширины блока по `compactness`.
- Сдвиг блока к стороне мяча.

## 4. Рывки

Типы: в разрез за спину, наложение, андерлап, открывание под пас, отвлекающий рывок, рывок в штрафную под навес, возврат в оборону. Частота и тайминг по `off_the_ball`, `anticipation`, `work_rate`, роли, привычкам, стилю и намерению. Рывок за спину стартует, когда владелец мяча поднял голову (принимает решение), с контролем офсайда.

## 5. Прессинг

Триггеры из стиля: пас назад, плохой приём, мяч у бровки, игрок спиной к атакуемым воротам, пас вратарю. Прессингующий бежит по траектории, отрезающей ближайший пас. Интенсивность и длительность по `press_intensity`, контрпрессинг после потери по `counter_press` (3–6 с), затем переход в блок.
