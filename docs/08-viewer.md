# 08. Визуализатор с кружками

## 1. Задача

Показать матч так, чтобы простая графика читалась как настоящий футбол и по ней было видно разницу командных стилей и стилей игроков. Реплеи не сохраняются: матч считается движком в браузере в реальном времени.

## 2. Архитектура

- Vite + TypeScript + Canvas 2D. React допустим только для панелей.
- `fsim-wasm` работает в Web Worker. Воркер считает матч с выбранной скоростью и отправляет кадры (позиции, скорости, `facing`, `action_state`, события, отладочные данные) через transferable `ArrayBuffer`.
- Рендер 60 FPS с интерполяцией между двумя последними кадрами физики.
- Типы сообщений генерирует `ts-rs`.
- API движка для визуализатора: `new_match(config, squads, styles, context, seed)`, `step(n)`, `set_style(team, params)`, `load_scenario(id)`, `set_debug_layers(mask)`, `inspect(player)`.

## 3. Как сделать так, чтобы кружки выглядели как футбол

- Масштаб честный: кружок игрока около 0,8 м в радиусе на поле 105×68, номер внутри.
- Направление взгляда: короткая риска на кружке.
- Интенсивность бега: толщина обводки (шаг, бег, спринт).
- Мяч: размер и тень показывают высоту; при навесе тень отстаёт от мяча.
- Следы: тонкий затухающий хвост последних 2–3 с у каждого игрока (включается). По хвостам видно рисунок движения: рывки, наложения, сдвиг блока.
- Действия короткими знаками: линия паса с затуханием, линия удара, вспышка отбора, крестик фола, флажок офсайда, карточка, гол.
- Владеющая команда подсвечивается полосой у края поля.
- Две камеры: всё поле (тактическая) и следящая за мячом с приближением (ощущение трансляции).
- Плавность важнее детализации: интерполяция, ограничения ускорения в движке, отсутствие дрожания.

## 4. Управление

- Скорость 0,25×–16×, пауза, шаг по тику.
- Новый матч: составы, стили, схемы, контекст, seed. Перезапуск с тем же seed.
- Изменение параметров стиля ползунками по ходу матча с немедленным эффектом.
- Запуск сценария из библиотеки, повтор сценария с новым seed одной кнопкой.

## 5. Слои анализа

Включаются по отдельности:
- якорные точки и линии к ним;
- линия обороны и офсайда каждой команды;
- контур формы (выпуклая оболочка) и расстояние между линиями;
- распределение ролей в обороне: линии от прессингующего к цели, тени прикрытия, опека, страхующий;
- тепловая карта контроля пространства;
- кандидаты решения владельца мяча: 4 лучших стрелками с полезностью, выбранный подсвечен;
- рывки стрелками;
- текущее командное намерение текстом у края поля;
- усталость полосой над игроком.

## 6. Панели

- **Матч:** счёт, время, удары, xG, владение, PPDA, высота линии, метрики стиля в реальном времени.
- **Отпечаток стиля:** радар метрик команды за последние 15 минут поверх центроида пресета из отчёта `fsim styles` и живой прогноз классификатора («похоже на gegenpress 72%»). Связывает то, что видно глазами, с тем, что измерено.
- **Инспектор игрока** (клик по кружку): роль, привычки, атрибуты 1–100, эффективные навыки, усталость, мораль, уверенность, текущее решение и кандидаты, обязанность в обороне, метрики игрока за матч.
- **После матча:** тепловые карты касаний, средние позиции, сеть передач, считаются из памяти текущей сессии.

## 7. Режим сравнения

Два поля рядом, два движка в двух воркерах, одинаковые составы и seed, у одной команды разный стиль. Синхронное воспроизведение. Основной режим для визуальной оценки стилей.

## 8. Протокол визуальной оценки

Встроенная панель чек-листа. Для каждого пресета и сценария список того, что должно быть видно, с отметками «видно / не видно / спорно» и комментарием. Результаты экспортируются в JSON.

Примеры пунктов:
- `positional`: защитники расходятся широко при розыгрыше от вратаря; много коротких передач в треугольниках; терпеливый возврат мяча назад при закрытом центре.
- `gegenpress`: после потери 3–5 игроков мгновенно идут к мячу; высокая линия; короткие быстрые атаки после отбора.
- `low_block_counter`: две компактные линии у своей штрафной; после отбора первый пас вертикально; 2–3 игрока убегают в контратаку.
- `direct_long_ball`: длинные передачи на нападающего, борьба за подбор, полузащита подтягивается к месту приземления мяча.
- `wing_play`: фланговые защитники высоко, много навесов, игроки атакуют обе штанги.
- Роли: инвертированный вингер уходит в центр с мячом, классический остаётся у бровки; ложная девятка опускается между линиями; таргетмен стоит спиной и скидывает.
