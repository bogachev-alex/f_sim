# 01. Модель данных

## 1. Шкала атрибутов

Три слоя, которые нельзя смешивать:

1. **Хранение:** `f32` в диапазоне 0–1 для всех атрибутов, позиционных рейтингов и `weak_foot`.
2. **Влияние:** значение проходит через кривую отклика из `response_curves.json`, результат идёт в композиты. Типы кривых: `linear`, `logistic` (центр, крутизна), `piecewise` (узлы). Кривая задаётся на группу с переопределением для атрибута. Старт: физика логистическая с усилением верхней трети, техника и ментальные кусочно-линейные с умеренным усилением верха, черты личности линейные. Вычисление через таблицу на 256 значений с интерполяцией. Форма кривых калибруется.
3. **Отображение:** в визуализаторе и отчётах `round(1 + 99 × v)`, шкала 1–100. Только для человека.

Все коэффициенты в формулах записаны для эффективных значений 0–1.

## 2. Атрибуты игрока

**Физические (9):** `pace`, `acceleration`, `agility`, `balance`, `strength`, `stamina`, `natural_fitness`, `jumping_reach`, `recovery`.

**Технические (14):** `passing`, `crossing`, `long_shots`, `finishing`, `first_touch`, `technique`, `dribbling`, `heading`, `tackling`, `marking`, `free_kicks`, `corners`, `penalties`, `long_throws`.

**Ментальные (12):** `vision`, `decisions`, `anticipation`, `positioning`, `off_the_ball`, `composure`, `concentration`, `work_rate`, `teamwork`, `aggression`, `bravery`, `flair`.

**Вратарские (8):** `reflexes`, `handling`, `one_on_ones`, `aerial_command`, `kicking`, `throwing`, `rushing_out`, `gk_positioning`.

**Черты, влияющие на матч (5):** `consistency` (разброс формы дня), `big_matches` (форма при высоких ставках), `pressure_handling` (амплитуда колебаний уверенности), `temperament` (фолы и карточки после провокаций и ошибок), `leadership` (сглаживание падения командной морали).

**Физические данные:** `height_cm`, `weight_kg`, `preferred_foot` (L, R, both), `weak_foot` (0–1).

**Позиционные рейтинги:** позиция → 0–1 (GK, CB, FB, WB, DM, CM, AM, W, ST). На чужой позиции штраф к `positioning`, `decisions`, `off_the_ball` пропорционально разнице.

## 3. Композитные навыки (`composites.json`)

Композит = взвешенная сумма атрибутов после кривых отклика, затем собственная кривая навыка при наличии.

| Навык | Атрибуты и веса |
|---|---|
| `short_pass` | passing .45, technique .20, vision .20, first_touch .15 |
| `long_pass` | passing .40, vision .25, technique .20, crossing .15 |
| `cross` | crossing .60, technique .25, vision .15 |
| `control` | first_touch .55, technique .25, balance .10, composure .10 |
| `dribble` | dribbling .40, agility .20, acceleration .15, technique .15, balance .10 |
| `finish` | finishing .50, composure .20, technique .15, off_the_ball .15 |
| `long_shot` | long_shots .60, technique .25, composure .15 |
| `tackle` | tackling .45, positioning .20, strength .15, aggression .10, bravery .10 |
| `aerial` | jumping_reach .35, heading .35, strength .20, bravery .10 |
| `shield` | strength .45, balance .30, technique .25 |
| `awareness` | anticipation .40, concentration .30, vision .30 |
| `press_resist` | first_touch .30, composure .30, agility .20, vision .20 |
| `gk_shot_stop` | reflexes .45, handling .25, gk_positioning .30 |

Эффективный навык = композит × форма дня × модификатор уверенности × модификаторы усталости и контекста для своих групп атрибутов. Кэш пересчитывается раз в игровую минуту и по событию.

## 4. Роли (`roles/*.json`)

Роль задаёт смещение якорной точки по фазам, параметры рывков, бонусы полезности и обязанности в обороне. Минимум 20 ролей: вратарь-чистильщик, классический вратарь, центральный защитник с мячом, защитник-разрушитель, накладывающийся фланговый защитник, инвертированный фланговый защитник, опорник-разрушитель, глубоко лежащий плеймейкер, бокс-ту-бокс, мезала, атакующий полузащитник, теневой нападающий, инвертированный вингер, классический вингер, широкий плеймейкер, ложная девятка, таргетмен, нападающий в линию, прессингующий нападающий, оттянутый нападающий.

## 5. Игровые привычки (`traits.json`)

0–3 на игрока. Каждая привычка даёт бонус полезности конкретным кандидатам или смещает позиционирование: `cuts_inside`, `stays_wide`, `tries_long_shots`, `plays_one_twos`, `runs_in_behind`, `drops_deep`, `dives_into_tackles`, `holds_ball`, `plays_simple_passes`, `tries_killer_balls`, `gets_forward`, `stays_back`, `switches_play`, `dribbles_through_middle`.

Требование: эффект каждой привычки измерим в метриках игрока (`docs/07-validation.md`, раздел «Узнаваемость стилей игроков»).

## 6. Команда

- 11 стартовых, до 7 запасных.
- Схема: 4-3-3, 4-2-3-1, 4-4-2, 3-5-2, 5-3-2, 3-4-3 с базовыми точками в долях поля.
- Роль каждого игрока.
- Стиль: параметры по фазам (`docs/05-styles.md`).
- `tactical_familiarity` 0–1: множитель к точности позиционирования.
- `cohesion`: сыгранность пар 0–1, влияет на точность паса между ними и синхронность линии.
- Стандарты: исполнители, схемы угловых, схема защиты.

## 7. Контекст матча (`context.json`)

| Фактор | Влияние |
|---|---|
| Погода: дождь 0–1, ветер, температура | Дождь: штраф к `control` и `long_pass`, мяч катится быстрее. Ветер: снос высоких мячей. Температура: скорость усталости |
| Поле: размер, качество | Шум отскока и контроля; пространство за линией |
| Домашний матч, заполненность трибун | Мораль, уверенность, малый сдвиг судейства. Суммарно около +0,3–0,4 гола |
| Ставки матча 0–1 | Через `big_matches` и `pressure_handling` |
| Судья: строгость, склонность к преимуществу | Фолы, карточки |

## 8. Состояние игрока в матче

`fatigue`, `morale`, `confidence`, `form` (разыгрывается перед матчем), `yellow_card`, `facing`, `velocity`, `action_state`, текущее решение и время его принятия (для гистерезиса).

## 9. Генератор тестовых составов (`fsim-gen`)

- Игроки генерируются от архетипа (позиция + телосложение + стиль игрока) с корреляциями атрибутов: высокий рост коррелирует с `jumping_reach` и `strength` и отрицательно с `agility`.
- Параметр общего качества состава.
- Режим «одинаковые составы»: обе команды получают статистически эквивалентных игроков, различаются только стилем. Нужен для анализа матчапов.
- Режим «состав под стиль»: позиционной команде больше игроков с высоким `press_resist` и `short_pass`, прямолинейной больше высоких нападающих.
- Режим «состав против стиля»: заведомо плохое сочетание для проверки соответствия стиля составу.
